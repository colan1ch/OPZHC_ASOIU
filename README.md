## Рубежные контроли

### РК №1 — математическая статистика и проверка гипотез

Файл: [`РК1_Чернев_ИУ5-64Б.ipynb`](./РК1_Чернев_ИУ5-64Б.ipynb)

В работе рассматриваются оценка доверительной вероятности и необходимого объёма выборки, описательная статистика, доверительные интервалы, гистограммы и функции распределения. Также выполняются проверки гипотез с использованием критерия Пирсона χ² и критерия Колмогорова–Смирнова.

### РК №2 — имитационное моделирование сети передачи пакетов

Файл: [`rk2_var126.py`](./rk2_var126.py)

Моделируется двухканальная система передачи пакетов с генерацией трафика, задержками каналов и адаптивным подключением дополнительного ресурса после серии потерь. Рассчитываются количество переданных и уничтоженных пакетов, частота потерь и частота включения дополнительного ресурса.

## Использованные методы

- описательная статистика, доверительные интервалы и эмпирические функции распределения;
- критерии согласия Пирсона χ² и Колмогорова–Смирнова;
- интерполяция и численное исследование распределений;
- дискретно-событийное моделирование систем массового обслуживания;
- моделирование приоритетов, прерываний, очередей и ограниченных ресурсов;
- синхронизация потоков с помощью мьютексов, `asyncio.Lock` и посредника-официанта;
- анализ дедлоков и способы их предотвращения;
- построение блок-схем и диаграмм состояний в Mermaid;
- моделирование передачи пакетов с адаптивным подключением дополнительного ресурса;
- воспроизведение структуры отчёта GPSS World средствами Python.

## Стек технологий

- **Python 3** — реализация моделей и статистических расчётов;
- **Jupyter Notebook** — интерактивное выполнение семинаров и РК №1;
- **NumPy, SciPy, Pandas** — численные вычисления, обработка данных и статистические критерии;
- **Matplotlib** — построение графиков и визуализация результатов;
- **SimPy** — дискретно-событийное моделирование систем массового обслуживания и производственных процессов;
- **threading и asyncio** — многопоточная и асинхронная модели синхронизации;
- **Mermaid** — блок-схемы и диаграммы состояний;
- **Excel и Word** — исходные задания и отчёты.

## Установка и запуск

Для ноутбуков и Python-скриптов достаточно Python 3 и необходимых библиотек:

```bash
pip install numpy scipy pandas matplotlib simpy jupyter
```

Запуск Jupyter Notebook из корня проекта:

```bash
jupyter notebook
```

Отдельные скрипты запускаются из каталога проекта, например:

```bash
python rk2_var126.py
python "sem7/ИУ5-64Б Чернев taxi_sim.py"
python sem11/sampque.py
```

Файлы `.xlsx`, `.docx`, `.pdf` и `.md` предназначены для просмотра соответствующих заданий, отчётов и диаграмм.
